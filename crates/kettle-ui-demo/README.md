# kettle-ui-demo

Demo islands for [kettle-ui](https://crates.io/crates/kettle-ui): a contact
form, and a search-as-you-type list that loads in the background. Used by
hob's demo commands and by tests.

> **Most of the code in this project was written by AI** (Claude), with a
> person directing the design. It's an early prototype: expect bugs, and
> APIs that change between releases.
